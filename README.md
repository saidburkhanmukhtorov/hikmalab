# hikmalab

A centralized management service to control computer remotely. 
The centure of technology gave us more opportunity to learn, develop and discover things very very easly for free. You can have access to tons of lectures, books, articles all wisdom in the world almost for free. 
But this is not free. The giant companies are fighting for our attention and try to rob our time. This project is for controlling computers from one system, blocking unnecessary websites and applications. Giving access to only useful resources.
